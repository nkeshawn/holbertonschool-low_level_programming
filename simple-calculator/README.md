## Compile Command
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 calculator.c -o calculator

## Run Instructions
Run using ./calculator

## Supported Operations
1. Addition
2. Subtraction
3. Multiplication
4. Division

## Numeric Behavior
1. Addition, Subtraction and Multiplication only for integers.
2. Division displays 6 digits after decimal.

## Known Limitations
1. Only supports arithmetic operations using two values.
2. The calculator must be restarted after each operation.
